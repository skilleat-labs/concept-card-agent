주제: {topic}
개념 정의: {definition}

위 인프라 개념을 설명하는 SVG 다이어그램을 그려라.
배경은 어두운 네이비(#1A1A35)이므로 밝은 색 요소 위주로 구성할 것.

[규칙 — 반드시 지킬 것]
- 반드시 <svg viewBox="0 0 936 380" xmlns="http://www.w3.org/2000/svg" width="936" height="380"> 로 시작
- font-family="'Noto Sans KR', sans-serif" 를 루트 svg에 명시
- 허용 요소만 사용: rect, circle, text, line, path, g, defs, marker, polygon
- 배경 rect 없음 (투명 배경)
- 색상:
  * 박스 fill: #2B4FE8, #1E3A8A, #166534, #9A3412, #374151 중 선택
  * 텍스트: fill="#FFFFFF" (제목), fill="#A5B4FC" (설명)
  * 화살표/선: stroke="#7B9EFF"
- 텍스트 크기: 박스 제목 font-size="22" font-weight="700", 설명 font-size="16"

[레이아웃 — 가로 일렬 흐름만 허용]
박스를 왼쪽에서 오른쪽으로 일렬로 배치하고, 화살표는 오른쪽 방향 수평선만 사용.
절대로 선이 교차하거나 겹치면 안 됨.

viewBox 중심은 y=190 (380÷2). 모든 박스는 y=190 기준으로 위아래 대칭 배치할 것.

3개 박스 배치 (권장):
  박스A: x=30,  y=80, width=240, height=220  (중심 y=190)
  박스B: x=348, y=80, width=240, height=220  (중심 y=190)
  박스C: x=666, y=80, width=240, height=220  (중심 y=190)
  화살표1: x1=270 y1=190 → x2=348 y2=190
  화살표2: x1=588 y1=190 → x2=666 y2=190

4개 박스 배치 (복잡한 개념일 때):
  박스A: x=20,  y=90, width=190, height=200  (중심 y=190)
  박스B: x=256, y=90, width=190, height=200  (중심 y=190)
  박스C: x=492, y=90, width=190, height=200  (중심 y=190)
  박스D: x=728, y=90, width=188, height=200  (중심 y=190)
  화살표: 각 박스 오른쪽 끝에서 다음 박스 왼쪽으로, y=190 고정

중요: 박스 상단 y는 최소 70 이상, 박스 하단(y+height)은 최대 310 이하로 유지할 것

[텍스트 배치 — 박스 내부]
- 박스 제목: x=박스중앙x, y=박스y+46, text-anchor="middle"
- 박스 설명: x=박스중앙x, y=박스y+72, text-anchor="middle" (필요 시 y+92에 2번째 줄)
- 텍스트가 박스 width를 넘으면 반드시 2줄로 나눌 것 (1줄 최대 8자)

[절대 금지]
- 화살표와 텍스트가 겹치는 위치에 텍스트 배치 금지
- 화살표끼리 교차 금지 (가로 일렬이면 교차 자체가 발생하지 않음)
- 박스와 화살표가 겹치지 않도록 화살표는 반드시 박스 경계(edge)에서 시작·끝낼 것
- 화살표 위에 라벨 텍스트를 추가할 때는 화살표 y좌표 -18px에 배치할 것
- 대각선 화살표 금지
- 점선(dasharray)을 박스 내부 구분선으로 사용 금지

SVG 태그만 출력. 다른 텍스트 없음.
